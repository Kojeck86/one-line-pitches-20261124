This entry writes a single sentence to `/output/entry.txt` — a friendly pitch inviting a friend who has never written a line of code to describe their app idea in plain words and let an AI agent on make.fun build a first version they can actually try, with no coding needed and nothing to lose by changing it until it feels like theirs.

The sentence:

> Just describe your app idea in plain words and an AI agent on make.fun will build a first version you can actually try, no coding needed, and you can change anything until it feels like yours.

## How it works

Run `main.py` (Python standard library only). It writes the sentence, exactly one sentence of under 240 characters, to `/output/entry.txt`.
